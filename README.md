# 历史试卷 AI 双评批改器

这是一个由历史教师发起、设计和维护的试卷批改工具，希望用 AI 减少看卷、核分和整理成绩中的重复劳动，让教师把更多时间留给学生的具体问题。

它可以识别客观题选项，让两个 AI 分别批改历史材料题，再由教师核对、确认或调整成绩。批改后可以查看各题正确率，导出 Excel 或 CSV 成绩表。目前提供 **Windows 便携测试版（Beta）**，解压后即可启动。

**[下载 Windows 便携版（约 111 MB）](https://github.com/blueandnight/history-ai-dual-grader-portable/releases/download/v0.2.2-beta.1/history-ai-dual-grader-windows-x64-v0.2.2-beta.1.zip)**

下载 ZIP → 完整解压 → 双击 `启动批改器.bat` → 在自动打开的浏览器中使用。**不需要另外安装 Python 或 Node.js。**

## 1. 它能做什么？

- **少做一遍客观题核分。** 上传答卷照片，识别学生选择的选项，根据你设置的标准答案计算分数；标记不清、有涂改等情况留给教师复核。
- **给材料题多一份判断参考。** 两个 AI 分别批改同一份答案，你可以对照原卷，看两边在哪些地方给分、哪里有分歧。
- **减少重复确认。** 结果完整、各个给分点的判断一致且通过检查的答卷，可以批量确认；其余答卷可直接确认或调整总分，不必逐个评分点操作。
- **把分数整理到一起。** 客观题、主观题可以分开批改和导出；将同一份答卷的两部分对应好后，可以合并整卷成绩。分开上传时，可查看原卷并手动选择对应答卷，不会按上传顺序猜测是谁的试卷。
- **看清这次考试的问题。** 查看客观题各题正确率、平均分和成绩分布，导出 Excel/CSV。暂未关联或尚待处理的答卷，不妨碍其他有效结果的查看和导出。

答卷可以分几次上传，同一场考试的结果会汇总展示。不强制录入学生身份信息或导入花名册，也可以使用“快速匿名批改”处理临时作业。

## 2. 软件界面

主要操作集中在四个页面：

| 页面 | 用来做什么 |
|---|---|
| 考试管理 | 新建考试，准备试题、答案和分值 |
| 答卷批改 | 上传客观题或主观题照片，查看进度 |
| 终评与成绩 | 核对评分建议、确认成绩、统计和导出 |
| 系统管理 | 配置 AI 模型及相关设置 |

## 3. 下载与安装

**普通使用者只需下载上方的“Windows 便携版”。** 当前版本为 `v0.2.2-beta.1`，适用于 64 位 Windows 电脑。

1. 下载 ZIP 文件。
2. 右键选择解压，将整个文件夹解压到电脑上的可写位置。不要只从压缩包里拖出一个程序，保留 `_internal` 等配套文件。
3. 双击 `启动批改器.bat`。
4. 等待浏览器自动打开，在页面中操作；浏览器页面连接的是这台电脑上运行的软件。

使用结束后，可双击 `停止批改器.bat`。评分时请保持电脑和程序运行。

## 4. 第一次使用

1. **启动软件。** 按上面的步骤打开工作台。
2. **配置 AI。** 进入“系统管理”，点击“展开模型配置”，按所选服务填写模型和 API Key，并配置 AI-A、AI-B。照片批改需要模型能够读取图片。
3. **准备考试。** 在“考试管理”点击“新建考试”，导入 Word/PDF，核对试题、客观题正确选项、各题分值和主观题评分要求，再确认创建。
4. **上传答卷。** 在“答卷批改”选择客观题或主观题，添加照片。先核对实际准备发送给 AI 的内容，再确认隐私和模型调用。可以分批上传。
5. **查看批改结果。** 看两边的评分建议和待处理问题；遇到识别不清、漏题或评分分歧，结合原卷核对。
6. **确认成绩。** 符合条件的主观题答卷可批量确认；需要单独处理时，在“确认最终总分”中采用某个 AI 的分数，或填写自己的最终分数并保存。
7. **统计与导出。** 进入“终评与成绩”的“统一成绩”，查看本考试的成绩和分析，按需要导出客观题、主观题或整卷结果。需要合并整卷成绩时，先核对两部分是否属于同一份答卷。

第一次使用建议先拿几份不含学生身份信息的练习样卷走一遍流程，再决定怎样用于自己的日常阅卷。

## 5. 常见问题

**软件收费吗？**

软件本身免费开源。模型服务由使用者自行选择和开通。

**没有编程基础能用吗？**

可以直接使用便携版，不用配置开发环境。首次使用仍需要按说明填写模型服务信息和密钥。

**必须使用 DeepSeek 吗？**

不必。可以选择或自定义模型服务；能否正常批改照片，取决于该模型是否支持图片及配置是否正确。

**AI API Key 是什么？**

它是模型服务商提供的调用密钥，用来让软件使用你的模型账户。需要在相应服务平台获取，请像密码一样保管，不要公开。

**调用模型会产生费用吗？**

可能会。免费开源不代表模型调用免费，费用和额度以服务商为准，重新调用也可能产生费用。

**答卷会发送到哪里？**

数据保存在本机，调用云端模型时，选定的答卷图片或文本会发送给你配置的服务商。发送前请核对内容，处理姓名、学号等身份信息，并遵守所选服务的条款。

**客观题和主观题能分开批改吗？**

可以，两边都能独立查看、统计和导出。只有要合并整卷成绩时，才需要可靠地对应两部分答卷。

**AI 给出的分数能直接作为正式成绩吗？**

主观题 AI 分数是评分建议，涉及正式学业评价的重要结果须经教师审核。符合条件的答卷可以批量确认，不要求每份都逐点评分。客观题按标准答案计分，识别异常仍需核对。

**为什么 Windows 提示“未知发布者”？**

当前程序没有数字签名，可能出现此提示。请核对文件来自本仓库的 Release；不同电脑和安全软件的表现可能不同。

## 6. 当前版本与已知局限

当前版本为 **`v0.2.2-beta.1`，Beta 测试版**。

- 已使用合成答卷和模拟模型验证主要操作流程，尚未充分验证真实学生答卷的识别与评分准确率。
- 程序未做数字签名，不保证兼容全部 Windows 和安全软件环境。
- 程序内部仍可能显示旧名称及 `0.2.2-beta-dev` 构建标识，这与本次发布使用的既有程序一致。
- 教师只确认主观题总分时，软件不会据此推算教师确认的小题分数；AI 小题数据会与正式成绩区分。
