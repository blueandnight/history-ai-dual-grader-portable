# 本地真实答卷评测集

这里存放教师主动挑选、匿名化后的评测清单，不是正式作业数据目录，也不会被备份接口自动打包。

## 使用方式

1. 复制 `manifest.example.json` 为 `manifest.json`。
2. 只填入匿名 `case_id`、已经保存的 `submission_id`、教师复核后的 `gold_total`；可选填写 `max_total`。
3. 在电脑本机打开网页的“评测与审计”区域，点击“刷新”。程序只读取清单中明确列出的提交，不会扫描全部正式记录，也不会调用模型。

## 清单边界

- `submission_id` 必须是程序生成的 12 位十六进制编号。
- 不要在此目录保存学生姓名、学号、答案原文、照片路径、原图或 API Key。
- `±1 分一致率` 按 AI 建议分与教师金标准分的绝对误差不超过 1 分计算。
- `严重误差率` 默认按绝对误差大于等于 2 分计算，可在清单中调整 `severe_error_threshold`（0.5～100）。
- 缺少提交记录、任务失败、照片质量失败和排队中的样本不会计入有效评分分母。
- 汇总按 A/B、模型及评分版本区分完整、部分、缺失，并统计严重误差及教师给正分而模型给零的次数。误差只使用完整结果。
- 对比模型时使用同一份实际外发图片、同一题目范围和评分标准。可为同卷的两次独立运行各填一条清单记录并使用相同教师分。按卷对比前请核实两次输入一致。

评测统计只用于发现模型、提示词或评分规则变更后的质量变化，不能替代教师对正式成绩的复核。
